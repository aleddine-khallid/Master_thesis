# **GENERATIVE AI AS GENERAL PURPOSE TECHNOLOGY**
### A Panel Data Analysis of European Productivity and Industrial Output (2011–2024)

Abstract
The public release of ChatGPT in late 2022 marked a shift from routine automation to the automation of high-level cognitive tasks. This study investigates the economic impact of this "AI shock" across European industries.

Key Methodology & Results:

Index Creation: Mapped US-based AI exposure scores to Eurostat labor data to build a unique industry-level index.

Econometric Model: Employed a fixed effect model with a Difference-in- difference interaction approach on panel data (2008–2024) 

The Findings: Contrary to the "job replacement" narrative, the data shows no immediate spike in labor productivity. Instead, the analysis reveals a scale effect: highly exposed industries expanded, seeing significant increases in both Real Gross Value Added and total hours worked compared to low-exposure sectors.
